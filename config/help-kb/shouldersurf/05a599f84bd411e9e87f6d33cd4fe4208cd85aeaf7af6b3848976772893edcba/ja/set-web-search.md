ウェブ検索を使うと、会議に含まれていない情報を回答に取り込めます。競合の発表、仕様、期限を計算するための今日の日付などです。

**質問ごとにオンにする。** 3つの入力欄（会議中のクエリシート（入力した質問のみ）、ミーティングチャット、プロジェクトチャット）で、テキスト欄の左にある地球儀を使います。タップしてオンにし、送信します。送信するたびに自動でオフになるので、次の質問ではもう一度オンにしてください。クイックプロンプトのタイルは検索しません。代わりに、クイックプロンプトのエディタで検索するよう設定できます。

**回数。** Shoulder Surf AI では、プランごとに毎月の検索の利用枠があり、Plus と Pro ではより多くなります。地球儀の横にあるカウンターのピルで現在の状況がわかり、上限が近づくとオレンジになります。上限に達すると「上限に達しました」と表示され、アップグレードを提案します。

**対応するモデル。** Shoulder Surf AI では、検索はサーバーで実行されます。自分の API キーの場合は、「自分のAPIキー」の追加機能パックを持っていれば、Anthropic と OpenRouter のモデルがプロバイダー自身のツールで検索できます。料金はあなたのキーに請求されます。Apple のオンデバイスモデルと Apple Cloud は検索できません。その場合は地球儀が表示されず、検索できなかった回答にはその旨が表示されます（「ウェブ検索なし: Shoulder Surf AI が必要です」）。

**結果の見かた。** 検索を使った回答には「ウェブを検索しました」（チャットでは「ウェブ検索に基づく」）と表示されるので、モデルが会議の外の情報を使ったことがわかります。

サインアウトしていると、地球儀は表示されません。
