「設定」>「カメラ」

**「会議の開始時」。** 録音開始時にカメラをオンにするかどうかです：「オン」（デフォルト）、「オフ」、または「前回の会議と同じ」（前回カメラボタンをどうしたかを覚えておきます）。オフにするとバッテリーが長持ちし、iPhone が熱くなりにくくなります。会議中はいつでもカメラのオン・オフを切り替えられ、「画面を読む」では常にカメラを使います。この設定はデバイスごとに保存され、同期はされません。

**「キャプチャモード」。** 「オーディオ」（通常のモード）か「字幕」のどちらかです。「字幕」は「画面を読む」のことで、音声を録音する代わりに、カメラで画面上のライブ字幕を読み取ります。「字幕エリアを設定」で、お使いの会議ツールで字幕が表示される位置を指定します（レイアウトごとに1回）。「字幕設定ガイドを再表示」で、手順の案内をもう一度表示します。

**「画像品質」。** 質問と一緒に送る写真のサイズです。自分の API キーでは、長辺が「オリジナル」、2048、1024、512 px から選べます。小さいほど料金が安く、スライドやグラフには十分です。デフォルトは 1024 です。Shoulder Surf AI ではプランによって管理され、この行にはサイズが表示されるだけです。この設定が影響するのは AI に送るものだけで、会議と一緒に保存される写真はフルサイズのままです。

**「確認メッセージをリセット」**で、アプリが一度だけ表示するカード（カメラを初めてオフにしたときの「写真があるとAIが画面の内容を理解できます」カードなど）が再び表示されるようになります。

会議の途中でカメラをオフにするのは、録音画面で行います。「カメラでスライドや画面をキャプチャする」をご覧ください。
