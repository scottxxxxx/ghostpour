Companion には Windows 版もあります。Windows 10 と 11（x64 と ARM64）向けの小さなタスクトレイアプリで、Microsoft Store で入手できます。

**できること。** Mac 版 Companion と同じ役割です。通話のシステム音声とあなたのマイクを2つのトラックとして取り込み、iPhone にストリーミングします。カメラボタン用にディスプレイのスクリーンショットを送ることもできます。また、半透明の回答ウィンドウ（「このPCに回答を表示」）があり、各回答の全文を表示して、この会議の回答を前後にたどれます。このウィンドウは Windows 自体が画面共有、録画、スクリーンショットに映らないようにします。「パソコンの画面に回答を表示する」をご覧ください。

**ペアリング。** コードでのみ行います。Windows には iCloud がないためです。iPhone がネットワーク上の PC を見つけるので、「設定」>「オーディオ」>「パソコン」>「Shoulder Surf Companion」で PC の6桁のコードを一度入力します。初回の起動時に Windows ファイアウォールの確認が表示されるので、プライベートネットワークで許可してください。

**Mac 版との違い。** Windows ではクイックプロンプトのキーボードショートカットはありません（Control と矢印キーの組み合わせをグローバルに使うと、すべてのアプリで単語単位の移動が効かなくなるためです）。「Present」ウィンドウもありません。Mac と PC が両方ネットワーク上にある場合は、「このネットワーク上のパソコン」から使いたいほうを選んでください。

ペアリングが済めば、あとはすべて同じです。聞き取り方法のピルを Shoulder Surf Companion にして球をタップすれば録音が始まり、PC との接続が切れても iPhone のマイクが自動的に引き継ぎます。
