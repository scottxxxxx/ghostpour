Voice ID は、どの話者があなたなのかをアプリが知るためのしくみです。一度登録すれば、すべての文字起こしであなたの発言に「話者2」ではなく「あなた」というラベルが付き、メモリーもどの約束があなたのものかを把握できます。

**登録する。** 「設定」>「声の識別」>「音声を登録」を開きます。いくつかのフレーズを約30秒間、声に出して読みます。レベルメーターが調整を促してくれます（「もう少し大きな声で話してください」、「大きすぎます！」）。「声を保存」をタップします。初回設定の「あなたの声を学習しましょう」のページでも登録を勧められます。そこでスキップしても問題ありません。いつでも登録できます。

**メモリーでのリマインダー。** アカウントでメモリーがオンになっていて、まだ登録していない場合は、メモリーの下部に「メモリーはあなたの声を知っているとより役立ちます」というカードが表示されます。「詳細」で理由を確認でき、「自分の声を登録」もあります。閉じると数日間は表示されず、何度か閉じると表示されなくなります。

**自分を指定する。** 「あなた」バッジの付いたプロファイルが本人のものです。先にほかの人を登録した場合や、複数のプロファイルがある場合は、正しいプロファイルで「これが私の声です」をタップしてください。

**ほかの人。** 同僚も会議から登録できます。文字起こしを開き、話者の名前をタップして「音声を登録」を選びます。その人の今後の会議には自動でラベルが付きます。プロファイルは名前を変更（鉛筆アイコン）したり、削除（スワイプ）したりできます。「すべてのプロファイルを削除」ですべて消去できます。いつでも登録し直せます。

**同じ画面の「Voice IDをテスト」**で、簡単なチェックを実行できます。声の似ているプロファイルが2つある場合は、「認識に関する警告」セクションでお知らせします。

**精度を上げる。** 登録し直すと、保存されている声が置き換わります。より静かな場所でもう一度録音するのが、照合の精度を上げる方法です。

**保存場所。** 登録時の音声と声の特徴データは iPhone に保存されます。iCloud同期がオンなら、あなたのプライベートな iCloud を通じてほかのデバイスにも送られるので、iPad で登録し直す必要はありません。

Voice ID をまったく使わなくても、アプリは話者を区別します。名前を付けるまでは「話者1」、「話者2」のように呼ぶだけです。
