セットアップ中に、「Appleでサインイン」ボタン付きの「Shoulder Surf AIを試す」と、その下の「スキップしてオンデバイスAIを使用」ボタンが表示されます。どちらを選んでもかまいません。違いは次のとおりです。

**スキップする。** アプリは iPhone 上の Apple Intelligence で動きます（お使いのデバイスが対応している場合）。録音、文字起こし、話者ラベル、要約、ライブ質問、ミーティングチャット、写真、手動のタグ、ファイルでの共有：すべて使えます。会議に関する情報は Shoulder Surf のサーバーに一切送られません。使えないのは、ミーティングレポート、プロジェクトチャット、メモリーと人物、翻訳です。これらはサーバー上で動き、ひも付けるアカウントが必要なためです。

**サインインする。** サインイン方法は Appleでサインインのみで、メールアドレスとパスワードは使いません。毎月の無料のクラウド AI 利用枠（Free プランで一般的な使い方なら約5時間分）、ミーティングレポート（Free では毎月決まった数）、会議を重ねるごとに蓄積されるメモリーと人物、プロジェクトチャット、翻訳が使えるようになります。サインインすると、それまでの設定（自分のキーを含む）にかかわらず、AI モデルが Shoulder Surf AI に切り替わります。「設定」>「AIモデル」からいつでも元に戻せます。

サインインで送られるもの：会議の文字起こし、要約、質問、チャットが、これらの機能のために Shoulder Surf のサーバーに送られます。音声の録音と、入力した API キーはデバイスに残ります（同期がオンの場合のあなた自身の iCloud は、あなたのものであり、当社のものではありません）。

**あとからでも大丈夫です。**「設定」>「アカウント」>「サインイン」。有料プランもサインインは必須ではありません。先にサブスクリプションに登録し、あとでサインインしてプランをほかのデバイスに引き継ぐこともできます。レポート、メモリー、人物は、Appleでサインインした時点から始まります。

アカウントはあなたの Apple ID です。Apple ID にアクセスできなくなると、サーバー側のデータを取り戻す方法はありません。Apple ID は大切に管理してください。
