Shoulder Surf AI には3つのプランがあります。価格は App Store の情報がアプリ内に表示されます（Plus と Pro は月額サブスクリプションで、Plus には1週間の無料トライアルがあります）。

**Free。** 誰が何を言ったかがわかるライブ文字起こしと要約。共有できるミーティングレポートが毎月決まった数（Apple のモデルより Shoulder Surf AI のほうが多く）作成でき、どの言語でもリンクとして共有できます。人物ページ。iCloud 同期とバックアップ。そのほかの機能を試せる、約5時間分の毎月のクラウド AI 利用枠：ライブ質問、ミーティングチャット、直近10日間の会議を対象にしたプロジェクトチャット、毎月の利用枠内でのウェブ検索とファイル生成、質問に添える写真。メモリーはプレビューとして表示されます。利用枠は毎月リセットされます。使い切ったら、リセットされるまでオンデバイスか自分のキーに切り替えるか、アップグレードしてください。

**Plus。** 無料トライアルの終了後も、会議中と会議後の質問に毎月の上限がありません。メモリー（Context Quilt）がオンになり、約束、好み、障害が会議をまたいで記録され、すべての回答に生かされます。直近30日間の会議を対象にしたプロジェクトチャット。ドキュメントを添付すると、回答はすべてのページを読みます。毎月のウェブ検索の回数が増えます。どのチャットからでも本物の Excel、Word、PowerPoint、PDF ファイルを作成できます。1つの質問に複数の画像。

**Pro。** Plus のすべてに加え、より強力なモデルがレポートと会議後の分析を作成します。これまでに録音したすべての会議を対象にしたプロジェクトチャットで、長い会議や大きなドキュメントも1つの質問に収まります。要約のスタイルを選べます（全文、または新しい内容だけ）。ウェブ検索の回数が最も多く、1つの質問に添えられる画像も増えます。

**プランに関係ないもの。** 録音、文字起こし、話者の分離、Voice ID は iPhone 上で動き、無料です。レポート、共有、人物はすべてのプランで使えます。Apple のオンデバイスと Apple Cloud は、それぞれ独自の上限がある無料のモデルです。自分のキーの料金はそのプロバイダから請求されます。Apple Cloud と自分のキー向けの買い切りの追加機能パックは、これらのプランとは別のものです。「Apple Cloud と自分の API キー向けの追加機能パック」をご覧ください。

**確認する場所。**「設定」>「アカウント」と「設定」>「AIモデル」のどちらでも、現在のプランとその上のプランを確認できます。無料プランでは、どちらにも 80% を超えるとオレンジ色になる利用量メーターも表示されます。

正確な利用枠（ウェブ検索、ファイル生成、1つの質問あたりの画像数、Free の利用枠）はサーバー側で設定されてアプリにリアルタイムで表示され、変更されることがあります。
