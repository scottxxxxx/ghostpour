参考資料は、AI が質問と一緒に読めるようアプリ内に保存しておくドキュメントです。従うべき状況報告の書式、照らし合わせる作業範囲記述書（SOW）、FAQ、概要資料などです。

**場所。** 「設定」>「プロンプトと参考資料」>「参考資料」。追加する方法は3つあります：**「テキストを入力または貼り付け」**、**「テキストとして追加」**（テキストと Markdown はそのまま、PDF、Word、RTF は編集可能なテキストに変換されます）、**「元の書式を保持」**（サーバーがそのまま読める形式のファイルについて、ファイル自体を保存します）。

**使い方。** プロジェクトチャットとミーティングチャットで、+ >「参考資料とプロンプト」を開き、使いたいものにチェックを付けます。外すまで、その会話に添付されます。会議中のクエリシートにも参考資料のセクションがあり、そこで添付した参考資料はその会議のすべての質問に添付されます。クイックプロンプトにも、実行するたびに参考資料を添付させることができます（プロンプトを編集 >「参考資料」）。プロジェクトを限定した参考資料（「これらのプロジェクトのみ」）は、そのプロジェクト内のすべての質問に自動で添付されます。「すべてのプロジェクト」はどこでも選べるという意味で、自動では添付されません。

**元のファイルを読むのは誰か。** Plus または Pro プランで Shoulder Surf AI を使う場合、元の PDF はページごとに読まれ（数百ページまで）、Word、PowerPoint、Excel の元ファイルはサーバーで読まれます。ほかのモデル、それより下のプラン、またはプレーンテキスト形式の場合は、抽出したテキストが質問と一緒に送られます。追加機能パックを使って自分の API キーで利用する場合、元の PDF は Claude、Gemini、OpenAI、OpenRouter のモデルに直接送られます。現在のモデルで使えない参考資料は、黙って品質を落とすのではなく、ピッカーにその旨が表示されます（「Shoulder Surf AIのみ」）。

**AI が作成したファイル**（プロジェクトチャットやミーティングチャットから）は自動で参考資料に入るので、あとで再び添付できます。

**デバイス間での同期。** iCloud同期がオンの場合、参考資料はあなたのプライベートな iCloud を通じて同期されます。

Keynote、Pages、Numbers のファイルは読み取れません。先に PDF に書き出してください。テキストレイヤーのないスキャンした PDF は、Shoulder Surf AI では問題なく使えますが（画像として読まれます）、それ以外では中身が空になります。
