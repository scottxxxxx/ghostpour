Web search lets an answer pull in something that isn't in your meeting: a competitor's announcement, a spec, today's date for a deadline.

**Turn it on per question.** The globe to the left of the text field in the three composers: the live Query sheet (typed questions only), Meeting Chat and Project Chat. Tap it on, send. It switches itself off after each send, so flip it again for the next question. Quick Prompt tiles never search; a Quick Prompt can be set to search in its editor instead.

**How many.** Each plan on Shoulder Surf AI has a monthly allowance of searches; Plus and Pro include more. A counter pill beside the globe shows where you stand and turns orange near the cap; at the cap it reads "limit reached" and offers the upgrade.

**Which models.** Shoulder Surf AI, where the search runs on the server. On your own key, Anthropic and OpenRouter models can search through the provider's own tool once you own the Own API Key Extras pack; that's billed to your key. Apple On-Device and Apple Cloud can't search; the globe is hidden there, and an answer that couldn't search says so ("Didn't search the web: that needs Shoulder Surf AI").

**Reading the result.** An answer that used search is marked "Searched the web" (or "Based on web search" in chats), so you know when the model went outside the meeting.

Signed out, there's no globe.
