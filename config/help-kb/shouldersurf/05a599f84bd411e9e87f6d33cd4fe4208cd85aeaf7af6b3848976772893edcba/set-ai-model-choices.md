Settings > AI Model. Pick a provider in the picker, read the capability list, tap **Use This Model**. The choice takes effect on your next question.

**Shoulder Surf AI.** Sign in with Apple and we handle the AI. The model is picked for you per task (a stronger one writes reports on Pro). Everything in the app works here: live questions with streaming answers, Memory recall, web search, documents read page by page, file generation, reports, translation, Project Chat. Free comes with a monthly allowance; Plus and Pro remove the cap. Signing in anywhere switches you to this.

**On-Device (Apple).** Apple Intelligence on the phone. Free, works offline, nothing leaves the device for a question. Needs a device that supports Apple Intelligence with it turned on. It's small: it reads the newest part of a transcript, can't look at photos, doesn't run post-meeting analysis (no sentiment, urgency or tags), and can't do Project Chat. It's also the safety net: when Shoulder Surf AI can't be reached, live questions fall back to it.

**Apple Cloud.** Apple's Private Cloud Compute, which keeps your data private. Free, with a daily limit set by Apple. Needs iOS 27 and an Apple Intelligence device; it only appears in the list when the phone qualifies. Out of the box: live questions, a photo with your question, summaries, Meeting Chat. With the Apple Cloud Extras pack: Project Chat, files, post-meeting analysis, streamed answers, more than one photo per question. No Memory recall, web search or file generation (those are server-side). See "Apple Cloud."

**Your own key.** OpenAI, Anthropic, Google Gemini, xAI, DeepSeek, Kimi, Qwen, OpenRouter. You pay the provider. Keys live in the iPhone Keychain and never leave the device. See "Using your own API key."

**What's managed on Shoulder Surf AI.** Model choice, image resolution, summary strategy and frequency, the background prompts, and global instructions are set by your plan. The capability rows on the AI Model page show, per model, what's open and what's locked.

Reports, translation and Memory capture always run through your Shoulder Surf AI account when you're signed in, whichever model you pick for questions.
