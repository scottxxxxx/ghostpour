Réglages > Modèle d'IA. Choisissez un fournisseur dans le sélecteur, lisez la liste de ce qu'il sait faire, touchez **Utiliser ce modèle**. Le choix s'applique à votre prochaine question.

**Shoulder Surf AI.** Connectez-vous avec Apple et on s'occupe de l'IA. Le modèle est choisi pour vous selon la tâche (un modèle plus puissant rédige les rapports avec Pro). Tout fonctionne ici : questions en direct avec réponses en continu, rappel de la Mémoire, recherche web, documents lus page par page, création de fichiers, rapports, traduction, Chat de projet. Gratuit inclut un quota mensuel ; Plus et Pro suppriment la limite. Se connecter, où que ce soit dans l'app, vous fait passer sur ce modèle.

**Sur l'appareil (Apple).** Apple Intelligence sur le téléphone. Gratuit, fonctionne hors ligne, rien ne quitte l'appareil pour une question. Nécessite un appareil compatible avec Apple Intelligence, et qu'elle soit activée. Il est petit : il lit la partie la plus récente d'une transcription, ne peut pas regarder les photos, ne fait pas l'analyse après la réunion (pas de ton, d'urgence ni d'étiquettes) et ne peut pas faire le Chat de projet. C'est aussi le filet de sécurité : quand Shoulder Surf AI est injoignable, les questions en direct basculent sur lui.

**Apple Cloud.** Le Private Cloud Compute d'Apple, qui garde vos données privées. Gratuit, avec une limite quotidienne fixée par Apple. Nécessite iOS 27 et un appareil compatible avec Apple Intelligence ; il n'apparaît dans la liste que si le téléphone remplit les conditions. D'emblée : questions en direct, une photo avec votre question, résumés, Chat de réunion. Le pack Extras : Apple Cloud ajoute le Chat de projet, les fichiers, l'analyse après la réunion, les réponses en continu et plusieurs photos par question. Pas de rappel de la Mémoire, de recherche web ni de création de fichiers (tout ça se passe côté serveur). Consultez "Apple Cloud."

**Votre propre clé.** OpenAI, Anthropic, Google Gemini, xAI, DeepSeek, Kimi, Qwen, OpenRouter. Vous payez le fournisseur. Les clés sont stockées dans le trousseau de l'iPhone et ne quittent jamais l'appareil. Consultez "Utiliser votre propre clé d'API."

**Ce qui est géré avec Shoulder Surf AI.** Le choix du modèle, la résolution des images, la stratégie et la fréquence des résumés, les prompts d'arrière-plan et les instructions globales dépendent de votre formule. Les lignes de fonctionnalités de la page Modèle d'IA montrent, pour chaque modèle, ce qui est ouvert et ce qui est verrouillé.

Les rapports, la traduction et l'enregistrement dans la Mémoire passent toujours par votre compte Shoulder Surf AI quand vous êtes connecté, quel que soit le modèle choisi pour les questions.
