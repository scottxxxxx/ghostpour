Le menu ⋯ d'une réunion propose deux choses différentes. "Quelle est la différence ?" dans le même menu l'explique dans l'app ; voici la version complète.

**Partager la réunion (un lien).** Toute la réunion est envoyée sur les serveurs de Shoulder Surf et vous obtenez un lien. Une personne qui a l'app le touche et la réunion s'ouvre directement dans son onglet Révision, où elle peut la traduire. Une personne qui n'a pas l'app voit le rapport sur une page web. Vous choisissez ce qui est transmis : requêtes et chat, le rapport, les fichiers générés par l'IA, les photos, l'audio. La transcription est toujours transmise. Le lien expire (à vous de choisir : 1, 7, 30, 90 ou 365 jours), et vous pouvez le révoquer à tout moment avec Arrêter de partager le lien. Toute personne qui a le lien peut l'ouvrir, sans connexion. Vous devez être connecté pour en créer un. Consultez "Partager un lien."

**Exporter les fichiers (des fichiers ordinaires).** Des fichiers classiques : la transcription en .txt, les sous-titres en .srt, l'audio en .m4a, le résumé, le rapport en HTML, vos requêtes et le chat en HTML, les photos, dans n'importe quelle combinaison. Ils passent par la feuille de partage d'iOS vers Mail, Dropbox, WhatsApp, Fichiers, où vous voulez. Rien n'est hébergé, aucune app n'est nécessaire pour les ouvrir, et c'est une copie : elle n'est jamais mise à jour et ne peut pas être révoquée. Vous pouvez choisir une langue pour les fichiers texte avant l'envoi. Au-delà de quelques mégaoctets, l'app suggère AirDrop.

**Une réunion partagée inclut la transcription complète.** Tout ce que vous envoyez devient une copie chez le destinataire. Ne partagez que ce que vous accepteriez de lui voir conserver.

Envoyer comme fichier de réunion (un fichier .shouldersurf) a été retiré en novembre 2026 : un fichier envoyé par Messages ne pouvait pas ouvrir l'app, c'est donc Partager la réunion qui s'en charge désormais. Un fichier .shouldersurf que vous avez déjà s'ouvre toujours dans Shoulder Surf.

Il existe aussi une app iMessage : dès qu'une réunion a un lien de partage, elle apparaît dans le tiroir d'apps Shoulder Surf de Messages sous forme de carte que vous pouvez glisser dans une conversation. Les liens se créent dans l'app, pas dans Messages.
