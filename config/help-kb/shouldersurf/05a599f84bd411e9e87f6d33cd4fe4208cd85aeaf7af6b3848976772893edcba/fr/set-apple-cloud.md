Apple Cloud, c'est le grand modèle d'Apple qui tourne sur Private Cloud Compute, les serveurs d'Apple conçus pour protéger la vie privée. Il est gratuit et se situe entre le petit modèle sur l'appareil et Shoulder Surf AI.

**Conditions.** iOS 27 ou une version ultérieure sur un appareil compatible avec Apple Intelligence, avec Apple Intelligence activée. Il n'apparaît dans Réglages > Modèle d'IA que si le téléphone remplit les conditions. S'il est dans la liste mais affiche "Apple Cloud n'est pas encore prêt", c'est qu'Apple Intelligence est encore en cours de configuration ou désactivée : Réglages d'iOS > Apple Intelligence et Siri.

**Limites.** Apple fixe un quota quotidien. Quand vous l'atteignez, les questions échouent avec "Vous avez atteint la limite du jour pour Apple Cloud. Choisissez un autre modèle dans Réglages, ou réessayez demain.", et l'app propose Shoulder Surf AI. Les résumés continus puisent dans le même quota à chaque intervalle. Il faut une connexion Internet. Sa fenêtre de contexte suffit pour la plupart des réunions prises une par une, mais pas pour un projet entier.

**Ce qu'il sait faire sans rien acheter :** les questions en direct et les instructions rapides, une photo par question, les résumés continus, le Chat de réunion.

**Avec Extras : Apple Cloud** (achat unique dans Réglages > Modèle d'IA) : le Chat de projet sur Apple Cloud, les fichiers joints (PDF, Word et RTF sont convertis en texte), l'analyse après la réunion (ton, urgence, étiquettes), les réponses en continu, plusieurs photos par question. Le pack est lié à votre identifiant Apple, il reste donc acquis même si vous vous déconnectez.

**Ce qu'il ne fera jamais :** le rappel de la Mémoire dans les réponses, la recherche web, les documents lus sur le serveur, la création de fichiers. Ce sont des fonctions de Shoulder Surf AI.

**Confidentialité.** Les questions et les photos jointes partent vers le Private Cloud Compute d'Apple, selon les conditions d'Apple. Les serveurs de Shoulder Surf ne sont pas sur ce chemin. Les rapports, la traduction et l'enregistrement dans la Mémoire passent quand même par Shoulder Surf AI quand vous êtes connecté, comme avec tous les modèles.
