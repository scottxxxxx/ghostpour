**Tags.** São oito tags integradas: Revisar, Acompanhamento, Agendar reunião, Pesquisar, Compartilhar, Importante, Tarefas, Decisão tomada. Adicione as suas em Ajustes > Reuniões > Tags (ou digite uma no popover "+ Tag" de uma reunião). As tags personalizadas sincronizam com seus outros aparelhos. Renomear uma tag personalizada não muda o nome dela nas reuniões antigas. O seletor "+ Tag" lista as integradas; para reaproveitar uma tag personalizada, digite de novo.

**Tags sugeridas pela IA.** Depois de uma reunião, a análise escolhe de uma a quatro tags integradas e dá um motivo de uma linha para cada uma. Essas tags ganham um pequeno brilhinho roxo. Toque em qualquer tag para ver por que ela está ali ("Sugerido pela IA" com o motivo, ou "Etiqueta atribuída manualmente") e para usar Remover tag, que pede confirmação. O relatório também sugere tags com motivos.

**Sentimento.** O emoji no topo do cartão. Rótulos: informativo, positivo, colaborativo, cauteloso, pressionado, tenso, desconectado, decidido. Toque nele para ver o motivo.

**Urgência.** O orbe colorido ao lado do emoji: verde é baixa, amarelo média, laranja alta, vermelho crítica. A cor do cartão acompanha, então um cartão vermelho quer dizer "faça algo a respeito". Quando existe um relatório, é o semáforo dele que define a cor.

**De onde isso vem.** A análise pós-reunião roda depois de qualquer reunião de uns dois minutos ou mais (Ajustes > Reuniões > Resumos > Analisar reuniões automaticamente, com um seletor de Duração mínima). Reuniões longas o bastante para ter relatório recebem as mesmas coisas pelo relatório. Qual IA faz isso:

- Shoulder Surf AI: sim.
- Sua própria chave: sim, com o pacote Extras de chave própria.
- Apple Cloud: sim, com o pacote Extras do Apple Cloud.
- Apple no dispositivo: não. O modelo no dispositivo é pequeno demais, então essas reuniões ficam sem sentimento, urgência e tags sugeridas.

Reanalisar reunião, no menu ⋯, roda tudo de novo com o seu modelo atual.
