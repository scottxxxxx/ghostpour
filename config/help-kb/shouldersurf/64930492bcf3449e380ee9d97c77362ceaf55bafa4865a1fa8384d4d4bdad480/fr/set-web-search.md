La recherche web permet à une réponse d'aller chercher ce qui n'est pas dans votre réunion : l'annonce d'un concurrent, une fiche technique, la date du jour pour une échéance.

**Activez-la question par question.** Le globe à gauche du champ de texte, dans les trois zones de saisie : la feuille Requête en direct (questions tapées uniquement), le Chat de réunion et le Chat de projet. Touchez-le pour l'activer, puis envoyez. Il se désactive tout seul après chaque envoi, donc réactivez-le pour la question suivante. Les tuiles d'instructions rapides ne lancent jamais de recherche ; une instruction rapide peut en revanche être réglée pour chercher, depuis son éditeur.

**Combien.** Chaque formule avec Shoulder Surf AI inclut un quota mensuel de recherches ; Plus et Pro en comptent davantage. Une pastille compteur à côté du globe indique où vous en êtes et devient orange près de la limite ; une fois la limite atteinte, elle affiche "limite atteinte" et propose de changer de formule.

**Quels modèles.** Shoulder Surf AI, où la recherche se fait sur le serveur. Avec votre propre clé, les modèles Anthropic et OpenRouter peuvent chercher via l'outil du fournisseur une fois que vous avez le pack Extras : votre propre clé ; c'est facturé sur votre clé. Sur l'appareil (Apple) et Apple Cloud ne peuvent pas chercher ; le globe y est masqué, et une réponse qui n'a pas pu chercher le signale ("Pas de recherche web : elle nécessite Shoulder Surf AI").

**Lire le résultat.** Une réponse qui a utilisé la recherche porte la mention "Recherche web effectuée" (ou "D'après une recherche web" dans les chats), pour que vous sachiez quand le modèle est allé au-delà de la réunion.

Déconnecté, il n'y a pas de globe.
