Shoulder Surf は、仕事用のパソコンではなく、あなたの iPhone で動く会議コパイロットです。

iPhone のマイク（またはほかのいくつかの方法。「どう聞き取りますか？ 4つのモード」を参照）で会議を聞き取り、端末上でライブ文字起こしを作成し、随時更新される要約を保ち、話されている内容についての質問に答えます。回答は iPhone の画面に表示され、AirPods で読み上げることもできます。カメラでスライドや画面を撮影すれば、AI がそれも見て理解できます。

会議が終わると、アプリはすべてを「振り返り」タブに保存します。話者名付きの文字起こし、要約、共有できるレポート、タグ、アクションアイテム、写真、通話中に質問した内容です。使い続けるうちに、会った人や決まった事柄のメモリーが蓄積され、あとからの回答が経緯を踏まえたものになります。

**エアギャップ。** 仕事用のパソコンには何もインストールしません。アプリが通話に参加することはなく、画面共有に映ることもありません。ビデオ通話でも、対面の会議でも使えます。（オプションの Mac 版と Windows 版の Companion は、通話の音声を直接 iPhone に送るために自分のパソコンにインストールできる小さなアプリです。使いたい場合のためのもので、iPhone だけでも問題なく使えます。）

**3つのタブ。** 「コパイロット」（録音する場所）、「振り返り」（保存されたすべて）、「設定」です。

**AI は選べます。** Shoulder Surf AI（サインインが必要。毎月の無料枠があり、有料プランでさらに使えます）、iPhone 上の Apple Intelligence（無料、プライベート、小型）、Apple のクラウドモデル（無料。iOS 27 と対応デバイスが必要）、または OpenAI、Anthropic、Google などの自分の API キーで使えます。「設定」>「AIモデル」で選びます。
