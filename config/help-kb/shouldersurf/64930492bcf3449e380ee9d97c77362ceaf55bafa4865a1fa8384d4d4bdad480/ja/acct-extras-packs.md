サブスクリプションに登録するより Apple Cloud や自分の API キーで使いたい場合は、2つの買い切り購入で、本来は Shoulder Surf AI が必要な機能を使えるようになります。サブスクリプションではなく、一度買えばずっと使えます。

**追加機能：Apple Cloud。** Apple Cloud でのプロジェクトチャット（Apple の1日の上限の範囲内）、ファイルの添付（PDF、Word、RTF はテキストに変換されます）、会議後の分析（感情、緊急度、タグ）、1語ずつストリーミングされる回答、質問ごとに写真2枚以上。

**追加機能：自分のAPIキー。** 自分のキーでのプロジェクトチャット、Claude、Gemini、OpenAI、OpenRouter のモデルへの元の PDF の送信、Anthropic と OpenRouter の検索ツールによるウェブ検索（料金は自分のキーに請求されます）、会議後の分析、ストリーミングでの回答、質問ごとに写真2枚以上。

**追加機能：両方** は、2つのパックを別々に買うより安い価格です。すでに一方のパックを持っている場合は、もう一方へのより安いアップグレードが表示されます。

**購入場所。** 「設定」>「AIモデル」の、Apple Cloud または自分のキーのプロバイダの機能一覧の下にある「追加機能をロック解除」（買い切り購入）で、横に「購入を復元」があります。ロックされた機能に触れたときにも、アプリが適切なパックを提案します。Apple Cloud でプロジェクトチャットを開いたとき、2枚目の写真を添付したとき、ファイルを添付したとき、自分のキーでウェブ検索をオンにしたときです。

**パックに含まれないもの。** Shoulder Surf のサーバーで動くものすべて：回答でのメモリーの活用、サーバーでのドキュメントの読み取り、ファイルの生成、レポート、翻訳。これらには引き続きサインイン済みの Shoulder Surf AI アカウントが必要で、毎月の利用枠を使います。

**所有権。** Apple ID の App Store での購入と Shoulder Surf のアカウントに紐付くので、サインアウトや再インストールをしてもパックは失われません。新しいデバイスでは「購入を復元」で戻せます。オンデバイスの Apple Intelligence にはパックはありません。パックで使えるようになる機能には小さすぎるためです。
