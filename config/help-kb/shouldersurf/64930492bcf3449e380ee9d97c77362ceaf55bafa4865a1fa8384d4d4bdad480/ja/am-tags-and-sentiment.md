**タグ。** 標準のタグは8つです：「振り返り」、「フォローアップ」、「会議を予定」、「リサーチ」、「共有」、「重要」、「アクション項目」、「決定事項」。独自のタグは「設定」>「会議一覧」>「タグ」で追加できます（会議の「+ タグ」ポップオーバーで入力することもできます）。カスタムタグはほかのデバイスに同期されます。カスタムタグの名前を変えても、過去の会議のタグ名は変わりません。「+ タグ」の選択画面には標準のタグが並びます。カスタムタグを再利用するには、もう一度入力してください。

**AI が提案するタグ。** 会議のあと、分析によって標準タグから1〜4個が選ばれ、それぞれに1行の理由が付きます。こうしたタグには小さな紫色のキラキラマークが付きます。タグをタップすると、付いている理由（理由付きの「AIの提案」、または「手動で割り当てたタグ」）が表示され、「タグを削除」もできます（確認があります）。レポートも理由付きでタグを提案します。

**感情。** カード上部の絵文字です。ラベルは「情報共有」、「前向き」、「協力的」、「慎重」、「切迫」、「緊張」、「希薄」、「決断」です。タップすると理由が表示されます。

**緊急度。** 絵文字の横の色付きの球です：緑が低、黄が中、オレンジが高、赤が重大。カードの色合いもこれに合わせて変わるので、赤いカードは「対応が必要」という意味です。レポートがある場合は、レポートの信号の色が反映されます。

**どこから来るのか。** 会議後の分析は、約2分以上のすべての会議で実行されます（「設定」>「会議一覧」>「要約」>「ミーティングを自動分析」、「最小期間」の選択あり）。レポートが作成されるほど長い会議では、同じ情報がレポートから得られます。分析を行う AI について：

- Shoulder Surf AI：対応しています。
- 自分の API キー：自分のキー用の追加機能パックがあれば対応しています。
- Apple Cloud：Apple Cloud の追加機能パックがあれば対応しています。
- Apple オンデバイス：対応していません。オンデバイスのモデルは小さすぎるため、こうした会議には感情、緊急度、提案タグが付きません。

⋯ メニューの「会議を再分析」で、現在のモデルを使ってもう一度分析できます。
