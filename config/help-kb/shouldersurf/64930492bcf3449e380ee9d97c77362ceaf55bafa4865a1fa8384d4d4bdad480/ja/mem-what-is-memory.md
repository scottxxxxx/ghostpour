メモリーは、Shoulder Surf の中で会議をまたいで物事を覚えておく部分です。製品名は Context Quilt で、「振り返り」タブのメモリー表示は「あなたの Context Quilt」です。

**できること。** 会議が終わるたびに（サインインしている場合）、文字起こしが Shoulder Surf のサーバーに送られ、そこから事実が「パッチ」として抽出されます。決定事項、担当者と期限のある約束、障害、誰かが述べた好み、人物とその役割、目標、成果物などです。抽出されたパッチは、会議中のライブ質問、ミーティングチャット、プロジェクトチャットでの回答に生かされます。「先月 Dana に何を約束した？」と聞けば、今日誰もそのことに触れていなくても、回答はちゃんと知っています。

**メモリー表示の内容。** 今週のダイジェストです：「忘れていいことがN件」、今週のパッチのグリッド、「いま引いている糸」（いちばん動きの多い会議）、プロジェクトごとのパネル（「あなたが通い続けている場所」）。パッチをタップすると、それが出てきた会議に戻ります。プロジェクトのパネルをタップすると、そのプロジェクトのキルトが開きます。「これはどこで使われる？」のピルでは、一度話したことをチャットが知っているしくみを説明しています。

**利用できる人。** メモリーは Shoulder Surf AI の Plus と Pro プランに含まれます。Free ではプレビューとして、メモリーが役立ったはずの回答に紫色の「過去の会議N件が関連していました」ピルが表示され、キルトの代わりにアップグレード画面が表示されます。人物ページは、サインインしているすべてのアカウントで無料です。

**メモリーではないもの。** 閲覧できる文字起こしのコピーではなく（それは「振り返り」です）、iPhone の中にあるわけでもありません（iPhone はキャッシュするだけです）。また、意図的に厳選されています。「今週は取り上げるものがありません」は、何も残す価値がなかったという意味で、何かが壊れたわけではありません。

「メモリーに保存されるものと保存場所」、「人物ページ」、「メモリーを修正する」もご覧ください。
