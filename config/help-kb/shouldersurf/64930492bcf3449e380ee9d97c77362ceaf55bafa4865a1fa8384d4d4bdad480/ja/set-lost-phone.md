**いちばん良いのは、新しい iPhone を iCloud バックアップから復元することです。** サインイン状態も含め、すべてが戻ります。会議、音声、声のプロファイル、設定、API キーまで戻ります。何もする必要はありません。

**新規インストールしてから Apple でサインインし、iCloud同期がオンの場合。** 新規インストールでは、アプリは意図的に常にサインアウトした状態で始まります。同じ Apple ID でサインインすれば、同じアカウントに戻れます。

あなたの iCloud から戻るもの：音声付きの会議、文字起こし、要約、レポート、チャット、タグ、プロジェクト、声のプロファイル、「人物」の連絡先のリンク、参考資料、同期された設定とカスタムタグ。

もともと iPhone の中だけにあったわけではないので、サーバーから戻るもの：メモリーと「人物」、共有リンク、プランと利用状況。

もう一度入力するもの：自分で用意したプロバイダーの API キー（その iPhone のキーチェーンにしか保存されていません）。

必要なときに作り直されるもの：翻訳（会議を開いたときに、会議ごとに1回だけすばやくサーバーに問い合わせます）。

失われるけれど価値のないもの：閉じたヒントや一度だけの案内（もう一度表示されます）、「会議が中断されました」の復旧状態、準備カードが学習した時間帯の傾向（これは学習し直します）。

**何をもってしても復元できない唯一のもの**は、Apple ID そのものです。アカウントは Apple ID です。Apple ID にアクセスできなくなると、サーバー側のデータは失われます。

**紛失する前に：** iCloud同期をオンのままにしておき（「設定」>「バックアップと同期」。デフォルトでオンです）、アプリなしで開けるファイルがほしければ iCloud Driveバックアップも検討してください。
