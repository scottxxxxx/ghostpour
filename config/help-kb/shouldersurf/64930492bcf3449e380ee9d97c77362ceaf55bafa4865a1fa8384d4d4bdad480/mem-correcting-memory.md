Memory is extracted by an AI from imperfect transcripts, so it will get things wrong. Everything it says can be corrected, and corrections go back to the server so every surface agrees.

**A patch is wrong.** Tap it (in Memory, or in a meeting's Memories section). Tap the text to edit it, then Save. Change or clear the owner from the owner menu. Add or remove connections. "Refresh headline" asks for a new one-line summary. "Delete Memory" removes it; from the patch page this is immediate, with no confirmation, so read before you tap. In a meeting's Memories list, long-press for Edit or Delete, and Delete asks first.

**A person's description is wrong.** On their page, ⋯ > "This isn't right." Say what's wrong, optionally what's true, and choose "Stop describing them this way." Nothing is deleted from the meeting; the app just stops treating that line as true of them and rewrites the description from what's left. There's an Undo, and "See how this changed" shows the history.

**An insight is wrong.** Hold it, "Not true about <name>," then Suppress.

**The wrong person got the credit.** Naming a speaker in the transcript ("This is Dana," or renaming Speaker 3 to Dana) updates every memory from that meeting. If a first name is ambiguous the app asks "Which Dana?"

**Two people are really one, or one is really two.** From the People list or a person's page: Merge (with a slide to confirm and an undo) or "Keep separate." "This isn't a person" removes an entry that was never a person (a product name, a place), and that name stops being recognized.

**A misheard word.** Fix a Word on the meeting corrects the meeting's own text but does not reach the memory patches yet.

**What deleting a meeting does.** Deleting a meeting from Review removes it from your phone and iCloud, but the patches it produced stay in Memory. Delete those from the Memory view if you want them gone. Deleting a project untags its meetings and keeps its memory, scoped to that project; the dialog says so. Deleting your account deletes everything on the server.
