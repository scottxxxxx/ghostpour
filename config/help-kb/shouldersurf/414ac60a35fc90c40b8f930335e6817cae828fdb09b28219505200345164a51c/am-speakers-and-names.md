The app separates voices as it listens and labels them Speaker 1, Speaker 2, and so on. You, once Voice ID is set up, show as "You." Anyone else you've enrolled is labelled automatically. Everyone else waits for a name.

**Naming someone.** In the transcript, tap the speaker label on any of their lines:

- **This is <name>**: one tap for anyone your memory already knows.
- **Name Speaker** (or Rename): type a name. "Name Everywhere" applies it to every line the app attributed to that voice; "Name Only This Section" fixes one passage.
- **Not <name>**: that passage wasn't them. It becomes "Speaker ?" until you say who.
- **Enroll Voice**: teach the app this voice so next time it's labelled on its own.

Naming updates the summary's speaker names and the meeting's memories; a toast tells you how many memories changed. The "Speaker names updated / Re-analyze" banner offers to rewrite the summary with the new names.

**Which <name>?** Type a bare first name that matches more than one person in your memory and the app asks which one, with "Someone new" if it's neither. If the exact name is already taken, "Who is this?" asks for a last name or nickname so the two don't get merged. During a live meeting the same prompt also offers "<you> (you)."

**Overlap.** When two people talk at once the app can mark it as "Multiple" instead of guessing. Settings > Audio > "Mark talk-over as Multiple" (on by default).

**Start over.** ⋯ menu > Restore Original Speaker Labels puts back Speaker 1, Speaker 2.

**If the app keeps mixing two people up,** see "Wrong speaker labels."
