「設定」>「AIモデル」。ピッカーでプロバイダを選び、機能の一覧を確認して、**「このモデルを使用」**をタップします。次の質問から反映されます。

**Shoulder Surf AI。** Appleでサインインすれば、AI は当社が用意します。モデルはタスクごとに自動で選ばれます（Pro ではより強力なモデルがレポートを作成します）。アプリのすべての機能がここで使えます：回答がストリーミングされるライブ質問、メモリーの呼び出し、ウェブ検索、ページごとに読み込むドキュメント、ファイル生成、レポート、翻訳、プロジェクトチャット。Free には毎月の利用枠があり、Plus と Pro では上限がありません。どこかでサインインすると、このモデルに切り替わります。

**オンデバイス（Apple）。** iPhone 上の Apple Intelligence です。無料で、オフラインでも動き、質問のために何もデバイスの外に出ません。Apple Intelligence に対応し、それがオンになっているデバイスが必要です。小さなモデルなので、文字起こしの最新部分だけを読み、写真は見られず、会議後の分析（感情、緊急度、タグ）は行わず、プロジェクトチャットも使えません。また、安全網の役割もあります。Shoulder Surf AI に接続できないとき、ライブ質問はこのモデルで処理されます。

**Apple Cloud。** データのプライバシーを守る、Apple の Private Cloud Compute です。無料で、Apple が定める1日の上限があります。iOS 27 と Apple Intelligence 対応デバイスが必要で、条件を満たす iPhone の場合にだけ一覧に表示されます。そのままで使えるもの：ライブ質問、質問に添える写真、要約、ミーティングチャット。Apple Cloud の追加機能パックを使うと：プロジェクトチャット、ファイル、会議後の分析、ストリーミング回答、1つの質問に複数の写真。メモリーの呼び出し、ウェブ検索、ファイル生成は使えません（サーバー側の機能のため）。「Apple Cloud」をご覧ください。

**自分のキー。** OpenAI、Anthropic、Google Gemini、xAI、DeepSeek、Kimi、Qwen、OpenRouter。料金はプロバイダに支払います。キーは iPhone のキーチェーンに保存され、デバイスの外に出ることはありません。「自分の API キーを使う」をご覧ください。

**Shoulder Surf AI で自動管理されるもの。** モデルの選択、画像の解像度、要約の方式と頻度、バックグラウンドのプロンプト、グローバル指示はプランによって設定されます。「AIモデル」ページの機能の行で、モデルごとに何が使えて何がロックされているかを確認できます。

サインインしている場合、レポート、翻訳、メモリーの取り込みは、質問用にどのモデルを選んでいても、常に Shoulder Surf AI のアカウントを通じて実行されます。
