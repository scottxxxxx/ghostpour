Apple Cloud は、Apple のプライバシーを保護したサーバーである Private Cloud Compute 上で動く、Apple の大きめのモデルです。無料で使え、小さなオンデバイスモデルと Shoulder Surf AI の中間に位置します。

**必要な条件。** Apple Intelligence に対応したデバイスで iOS 27 以降を使い、Apple Intelligence をオンにしていること。iPhone が条件を満たしている場合にだけ、「設定」>「AIモデル」に表示されます。一覧には表示されているのに「Apple Cloudはまだ準備ができていません」と出る場合は、Apple Intelligence がまだ準備中か、オフになっています。iOS の「設定」>「Apple IntelligenceとSiri」を確認してください。

**上限。** Apple が1日あたりの利用上限を設けています。上限に達すると、質問は「本日のApple Cloudの上限に達しました。設定で別のモデルに切り替えるか、明日もう一度お試しください。」というメッセージで失敗し、アプリが Shoulder Surf AI を提案します。随時更新の要約も、間隔ごとに同じ上限を消費します。インターネット接続が必要です。コンテキストウィンドウはほとんどの会議1回分には足りますが、プロジェクト全体は入りません。

**何も購入せずにできること：** ライブ質問とクイックプロンプト、質問ごとに写真1枚、随時更新の要約、ミーティングチャット。

**「追加機能：Apple Cloud」を購入すると**（「設定」>「AIモデル」での買い切り購入）：Apple Cloud でのプロジェクトチャット、ファイルの添付（PDF、Word、RTF はテキストに変換されます）、会議後の分析（感情、緊急度、タグ）、ストリーミングでの回答、質問ごとに写真2枚以上。パックの所有権は Apple ID に紐付くので、サインアウトしても失われません。

**どうしてもできないこと：** 回答でのメモリーの活用、ウェブ検索、サーバーでのドキュメントの読み取り、ファイルの生成。これらは Shoulder Surf AI の機能です。

**プライバシー。** 質問と添付した写真は、Apple の規約のもとで Apple の Private Cloud Compute に送られます。Shoulder Surf のサーバーは経由しません。レポート、翻訳、メモリーへの記録は、どのモデルでも同じく、サインインしていれば引き続き Shoulder Surf AI に送られます。
