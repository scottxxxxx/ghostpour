会議のページにあるチャットのカード（「この会議について質問」）を開くと、その会議についての会話が始まります。

**最初の質問の例。** 「重要な決定は何でしたか？」、「主なトピックを要約」、「どのアクションアイテムが挙げられましたか？」、「意見の相違はありましたか？」。もちろん、自由に入力することもできます。

**含めるコンテキスト。** 上部のチップです。「文字起こし」、「要約」、「プロジェクト」、「メモ」（すべてオン）、「AI の回答」（オフ）、「Context Quilt」（オフ。Shoulder Surf AI と、メモリー付きのプランが必要です）。会話の一貫性を保つため、最初のメッセージを送るとこれらはロックされます。「チャット中はロックされます」に説明があり、新しい会話を始めるとロックが解除されます。

**添付。** + ボタンから「写真を撮る」、「フォトライブラリ」、「ミーティングの写真」、「参考資料とプロンプト」を選べます。写真には画像を認識できるモデルが必要です。Shoulder Surf AI でプランの検索回数が残っている場合（または追加機能パックのある自分の API キーの場合）、ウェブ検索の地球儀が表示されます。ウェブ検索を使った回答には「ウェブ検索に基づく」と表示されます。

**その場面に移動する。** 回答が会議中の特定の場面を指している場合、時間が色付きのリンク（例：24:20）として表示されます。タップすると、チャットの上にその位置の文字起こしが開きます。「戻る」で回答に戻ります。回答をコピーまたは共有すると、リンクは通常の時間表記になります。リンク付きの回答ではその場でのテキスト選択ができないため、一部をコピーしたいときは回答を長押しして「テキストを選択」を選んでください。

**回答から。** 「メールを作成」で、回答をメールの下書きにできます。回答にアクションアイテムが含まれている場合は、「N件のアクションをリマインダーに追加」チップが表示されます。

**使われる AI。** 「設定」>「AIモデル」で選んでいるモデルです。オンデバイスでも使えます（モデルが小さいため、文字起こし全文ではなく要約を読みます）。Apple Cloud はほとんどの会議に収まります。自分の API キーと Shoulder Surf AI は文字起こし全文を読み込みます。

複数の会議にまたがる質問には、そのプロジェクトのプロジェクトチャットを使ってください。
