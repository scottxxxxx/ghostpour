**グローバルシステム指示**は、AI に対する常設のルールです。たとえば「箇条書きで答える」、「推測はしない」、「製薬業界で働いているので、その前提で答える」など。「設定」>「プロンプトと参考資料」>「クイックプロンプト」>「詳細設定」にあります。すべてのライブセッションのプロンプトに加え、ミーティングチャットとプロジェクトチャットにも追加されます。

**自分の API キーでのみ適用されます。** Shoulder Surf AI、Apple Cloud、Apple オンデバイスでは指示は Shoulder Surf が管理しており、画面下部の注記にもそう書かれています。そこで保存した内容は残りますが、自分の API キーを使うモデルに切り替えるまでは使われません。理由は、これらのモデルではプロンプトの構成をサーバー側で管理し、モデルごとに調整しているため、独自のルールと衝突してしまうからです。

**クイックプロンプトのテキストは、どのモデルでも自由に変えられます。** Shoulder Surf AI でも、クイックプロンプトの編集、追加、並べ替え、削除ができます。「クイックプロンプト：ワンタップで回答」をご覧ください。

**バックグラウンドのプロンプト**（「完全な要約」、「差分要約」、「最終統合」、「セッション後の分析」）は、「設定」>「会議一覧」>「要約」>「要約プロンプトを編集」にあります。自分のキーでは編集でき、Shoulder Surf AI では管理されています（「Shoulder Surf AI 向けに最適化」）。Shoulder Surf AI に切り替えると、カスタムプロンプトは管理されたデフォルトに戻ります。

**コンテキストスロット。** 質問と一緒に送る内容です：文字起こし、随時更新の要約、プロジェクト情報、会話の履歴、画像、Context Quilt。各クイックプロンプトの「詳細設定」で、プロンプトごとに上書きできます（「デフォルト」/「オン」/「オフ」）。プロンプトはグローバルのデフォルトを引き継ぎます。

**「最新のデフォルトプロンプトを取得」**で、管理されている最新の文面をサーバーから取得します。標準のプロンプトをカスタマイズしている場合は自動では更新されないので、このボタンか「デフォルトに戻す」で新しいものを取り込んでください。
