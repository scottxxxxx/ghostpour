**「クエリ」**をタップし、「カスタム質問をする」を選びます。送信矢印付きの入力欄（「会議について何でも質問…」）が開きます。その下で、質問と一緒に送る内容を選びます。

**「ミーティングのどれだけを含めますか？」** 選択肢は「なし」、「直近2分」（シートを開くたびにこれがデフォルトです）、「直近5分」、「全文」、「前回の質問以降」（最初の質問のあとに選べるようになります）です。同じ設定がクイックプロンプトのタップにも適用されます。

**参考資料。** 「参考資料」の横の「添付」をタップすると、保存しておいた資料（書式、ブリーフ、FAQ など）を選んで、AI に質問と一緒に読ませられます。その場で新しく追加することもできます。「ファイルを追加」の「元の書式を保持」か「テキストとして追加」で「ファイル」アプリから PDF や Word などの書類を取り込めます。「テキストを入力または貼り付け」ならテキストから作れます。新しいファイルは参考資料に保存され、すぐに添付されます。鍵のマークが付いた項目は、タップすると何が必要か表示されます。添付した参考資料は、この会議の残りのすべての質問と一緒に送られます（「このミーティングのすべての質問と一緒に送信されます。」）。プロジェクトに設定した参考資料は自動で付きます。チップの × をタップすると、この会議では外せます。「参考資料：質問と一緒に AI が読むドキュメント」をご覧ください。

**写真を添付。** このセッションの写真か、フォトライブラリから選びます。1つの質問に複数の写真を送れます。テキストなしで写真だけを送ることもできます。Apple Cloud や自分の API キーを使っていて、対応する追加機能パックがない場合でも、質問と一緒に写真を送れます。写真は送信前にサイズが調整されます。

**ウェブ検索の地球儀。** 入力欄の左にあります。オンにすると、回答にリアルタイムのウェブ検索を使えます。送信するたびに自動でオフに戻るので、次の質問でも使うときはもう一度オンにしてください。地球儀が表示されるのは、Shoulder Surf AI で検索回数が残っているとき（どのプランにも毎月の利用枠があります）か、自分の API キー用パックで検索できる自分のキーを使っているときだけです。クイックプロンプトが検索することはありません。

**考えている間は、**「考え中…」のシートに「停止」ボタンが表示されます。「停止」で処理を取り消します。

**フォローアップ。** どの回答にも、下部に写真用の + が付いた「フォローアップ…」の入力欄があります。フォローアップは同じスレッド内で続き、元のプロンプトのスタイルを引き継ぎます。フォローアップに失敗した場合、エラーはスレッド内に表示されます。

入力した質問は「ミーティングのコンテキストなし」のチェックを受けないので、まだ誰も話していないうちでも一般的な質問ができます。ただし「なし」を選んでいると、AI は会議の内容を何も参照できない点にご注意ください。
