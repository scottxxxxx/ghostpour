Action items (the tasks a meeting leaves behind) show up in a few places, you can edit them, and the Reminders app is where you can send them.

**In the report.** Action Required lists owner, task, priority and deadline. You can edit this section in the report review.

**In the project.** Open the project for its Action items section: what the server extracted from meetings plus anything you add by hand (with an owner and an optional date). Mark done, reopen, see what's overdue. See "Projects."

**Changing one.** In the project's Action items, tap the pencil on an open item (or long-press it and choose Edit). "Edit item" opens with "What needs doing", "Whose is it?" and "Due". Change any of them and tap Save at the top right. Text and owner changes go to the server with the item; a changed date is kept on this phone for now. A completed item has no pencil, so tap Reopen first. For the report, open it from the meeting and tap the pencil at the top: in Action Required you can change each item's owner, task, priority and date, add one with +, or delete one.

**Confirm cards.** Near the top of a meeting page: "From this meeting, N to confirm." Each card is something the meeting seems to have closed out; "Yes, it did" or "Not yet" keeps the ledger honest. The same cards appear in the project.

**Alignment card.** Only when a meeting changed a project's direction. It asks "Does this accurately represent the current direction?" with Confirm or Suggest a correction, and a link to the Alignment Record.

**Sending to Reminders.** Three ways, all opt-in:

- During a meeting, a Quick Prompt with "Save to Reminders" turned on writes its answer's items to a Reminders list named after the project and date.
- In Meeting Chat or Project Chat, an answer with a list of items shows an "Add N action items to Reminders" chip.
- A project note of type Reminder has an "Add to iOS Reminders" switch.

The first time, iOS asks for Reminders access. If it was denied you'll see "Couldn't save to Reminders. Check Reminders access in Settings."

**Shortcuts.** The Shortcuts app has Get Meeting Action Items, Get Meeting Decisions, Get Meeting Summary, Get Meeting Transcript and Get Meeting Report, so you can pipe a meeting into anything else.
