Il existe aussi une version Windows du compagnon. C'est une petite app de la zone de notification pour Windows 10 et 11 (x64 et ARM64), disponible sur le Microsoft Store.

**Ce qu'elle fait.** Le même travail que le compagnon pour Mac : elle capte l'audio système de l'appel et votre micro sur deux pistes, et les envoie au téléphone. Elle peut envoyer des captures de vos écrans pour le bouton de la caméra, et elle propose une fenêtre de réponses transparente ("Afficher les réponses sur ce PC") avec le texte complet de chaque réponse et des flèches pour avancer ou reculer parmi les réponses de cette réunion. Windows lui-même tient cette fenêtre à l'écart des partages d'écran, des enregistrements et des captures d'écran. Voir "Les réponses sur l'écran de votre ordinateur".

**Le jumelage.** Par code uniquement ; il n'y a pas d'iCloud sur Windows. Le téléphone trouve le PC sur le réseau, et vous tapez une fois le code à six chiffres du PC dans Réglages > Audio > Ordinateur > Shoulder Surf Companion. Au premier lancement, le Pare-feu Windows vous posera la question ; autorisez l'app sur les réseaux privés.

**Les différences avec le Mac.** Pas de raccourcis clavier pour les instructions rapides sous Windows (une combinaison globale Contrôle + flèche volerait le saut de mot à toutes les apps). Pas de fenêtre "Présenter". Si un Mac et un PC sont tous les deux sur le réseau, choisissez celui que vous voulez dans "Ordinateurs sur ce réseau".

Une fois le jumelage fait, tout le reste fonctionne pareil : réglez la pastille d'écoute sur Shoulder Surf Companion, touchez la sphère, et le micro du téléphone prend le relais tout seul si le PC décroche.
