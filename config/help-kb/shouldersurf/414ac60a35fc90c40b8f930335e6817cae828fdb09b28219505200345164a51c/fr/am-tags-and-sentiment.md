**Étiquettes.** Huit étiquettes intégrées : Révision, Relance, Planifier une réunion, Recherche, Partager, Important, Actions à suivre, Décision prise. Ajoutez les vôtres dans Réglages > Réunions > Étiquettes (ou tapez-en une dans la fenêtre "+ Étiquette" d'une réunion). Les étiquettes personnalisées se synchronisent avec vos autres appareils. Renommer une étiquette personnalisée ne la renomme pas sur les réunions passées. Le sélecteur "+ Étiquette" liste les étiquettes intégrées ; pour réutiliser une étiquette personnalisée, tapez-la de nouveau.

**Étiquettes suggérées par l'IA.** Après une réunion, l'analyse choisit d'une à quatre étiquettes intégrées et donne pour chacune une raison en une ligne. Ces étiquettes portent une petite étincelle violette. Touchez n'importe quelle étiquette pour voir pourquoi elle est là ("Suggéré par l'IA" avec la raison, ou "Étiquette attribuée manuellement") et pour Retirer l'étiquette, ce qui vous demande de confirmer. Le rapport suggère lui aussi des étiquettes avec leurs raisons.

**Ton.** L'émoji en haut de la carte. Libellés : informatif, positif, collaboratif, prudent, sous pression, tendu, déconnecté, décisif. Touchez-le pour connaître la raison.

**Urgence.** La sphère colorée à côté de l'émoji : vert pour faible, jaune pour moyenne, orange pour élevée, rouge pour critique. La teinte de la carte la suit, donc une carte rouge signifie "à traiter". Quand un rapport existe, c'est son feu tricolore qui décide de la couleur.

**D'où ça vient.** L'analyse d'après réunion s'exécute après toute réunion d'environ deux minutes ou plus (Réglages > Réunions > Résumés > Analyser les réunions automatiquement, avec un sélecteur Durée minimale). Les réunions assez longues pour avoir un rapport obtiennent les mêmes éléments à partir du rapport. Quelle IA s'en charge :

- Shoulder Surf AI : oui.
- Votre propre clé : oui, avec le pack Extras pour votre propre clé.
- Apple Cloud : oui, avec le pack Extras Apple Cloud.
- Sur l'appareil (Apple) : non. Le modèle sur l'appareil est trop petit, ces réunions n'ont donc ni ton, ni urgence, ni étiquettes suggérées.

Réanalyser la réunion dans le menu ⋯ la relance avec votre modèle actuel.
