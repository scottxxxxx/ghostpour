Vous n'avez pas enregistré avec l'app ? Importez l'audio après coup.

**Importer un enregistrement.** Révision > Réunions > le menu Importer > Importer un enregistrement. Audio ou vidéo : m4a, mp3, wav, mp4, QuickTime. Choisissez un projet (ou aucun), puis l'app transcrit et sépare les intervenants sur l'appareil, exactement comme pour une réunion en direct. Les voix enregistrées sont reconnues ; tous les autres deviennent Intervenant N. L'analyse d'après réunion se lance si l'enregistrement est assez long. Il n'y a pas de résumé continu pour les imports, donc la section Résumé propose "Générer le résumé". Dictaphone sur le téléphone ou la Watch, enregistrement Zoom ou Teams, fichier d'un enregistreur vocal : tout fonctionne.

**Depuis la feuille de partage.** Dans Fichiers, Dictaphone ou n'importe quelle app, partagez un fichier audio ou vidéo et choisissez "Ajouter à Shoulder Surf". Vous choisissez le projet sur place ; l'import se fait la prochaine fois que vous ouvrez l'app. Plusieurs fichiers à la fois, aucun problème.

**Importer une réunion partagée (fichier .shouldersurf).** Quelqu'un vous a envoyé un fichier de réunion. Touchez-le, ou passez par le menu Importer. Une carte d'aperçu montre de qui il vient et ce qu'il contient, avec "Ajouter à ma bibliothèque". Il devient une copie dans votre Révision, avec un badge "Partagé par". Si vous l'avez déjà, vous pouvez choisir Remplacer ou Conserver les deux.

**Un lien de partage.** Touchez le lien ; la réunion se télécharge et la même carte d'aperçu apparaît, sans compte nécessaire. Si l'app n'est pas installée, le lien ouvre une page web avec le rapport.

**Les réunions partagées et votre mémoire.** Une réunion enregistrée par quelqu'un d'autre n'est pas ajoutée à votre Mémoire sauf si vous le demandez : "Ajouter cette réunion à votre mémoire ?" apparaît quand vous demandez un rapport ou choisissez "Ajouter à votre mémoire" dans le menu ⋯. Des propositions de traduction apparaissent aussi à l'ouverture ("Traduire cette réunion ?").
