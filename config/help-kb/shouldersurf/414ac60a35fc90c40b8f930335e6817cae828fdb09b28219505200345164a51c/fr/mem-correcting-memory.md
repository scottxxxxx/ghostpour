La Mémoire est extraite par une IA à partir de transcriptions imparfaites, elle se trompera donc parfois. Tout ce qu'elle dit peut être corrigé, et les corrections repartent au serveur pour que tous les écrans soient d'accord.

**Une pièce est fausse.** Touchez-la (dans Mémoire, ou dans la section Souvenirs d'une réunion). Touchez le texte pour le modifier, puis Enregistrer. Changez ou retirez le responsable depuis le menu du responsable. Ajoutez ou supprimez des liens. "Actualiser le titre" demande un nouveau résumé en une ligne. "Supprimer le souvenir" l'efface ; depuis la page de la pièce, c'est immédiat, sans confirmation, alors lisez avant de toucher. Dans la liste Souvenirs d'une réunion, faites un appui long pour Modifier ou Supprimer, et Supprimer demande d'abord confirmation.

**La description d'une personne est fausse.** Sur sa page, ⋯ > "Ce n'est pas exact". Dites ce qui ne va pas, éventuellement ce qui est vrai, et choisissez "Cesser de le décrire ainsi". Rien n'est supprimé de la réunion ; l'app cesse simplement de tenir cette ligne pour vraie à son sujet et réécrit la description à partir de ce qui reste. Vous pouvez Annuler, et "Voir comment cela a changé" montre l'historique.

**Une analyse est fausse.** Appuyez longuement dessus, "Faux au sujet de <nom>", puis Supprimer cette analyse.

**La mauvaise personne a été créditée.** Nommer un intervenant dans la transcription ("C'est Dana", ou renommer Intervenant 3 en Dana) met à jour tous les souvenirs de cette réunion. Si un prénom est ambigu, l'app demande "Quel Dana ?"

**Deux personnes n'en font qu'une, ou une seule en cache deux.** Depuis la liste Personnes ou la page d'une personne : Fusionner (avec un glissement pour confirmer et la possibilité d'annuler) ou "Garder séparés". "Ce n'est pas une personne" retire une entrée qui n'a jamais été une personne (un nom de produit, un lieu), et ce nom n'est plus reconnu.

**Un mot mal entendu.** Corriger un mot sur la réunion corrige le texte de la réunion elle-même, mais n'atteint pas encore les pièces de la Mémoire.

**Ce que fait la suppression d'une réunion.** Supprimer une réunion dans Révision la retire de votre téléphone et d'iCloud, mais les pièces qu'elle a produites restent dans la Mémoire. Supprimez-les depuis la vue Mémoire si vous voulez qu'elles disparaissent. Supprimer un projet retire l'étiquette de projet de ses réunions et conserve sa mémoire, limitée à ce projet ; la boîte de dialogue le précise. Supprimer votre compte supprime tout sur le serveur.
