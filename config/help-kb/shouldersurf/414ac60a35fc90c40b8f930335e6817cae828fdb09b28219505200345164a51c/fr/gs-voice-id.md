L'ID vocale permet à l'app de savoir quel intervenant est vous. Enregistrez votre voix une fois, et vos répliques dans chaque transcription seront libellées "Vous" au lieu de "Intervenant 2", et la mémoire saura quelles promesses sont les vôtres.

**Enregistrer votre voix.** Réglages > ID vocale > Enregistrer la voix. Vous lisez quelques phrases à voix haute pendant environ 30 secondes. Un indicateur de niveau vous guide ("Parlez un peu plus fort", "Trop fort !"). Touchez Enregistrer la voix. La configuration le propose aussi sur la page "Apprenons à reconnaître votre voix" ; vous pouvez passer cette étape, et le faire à tout moment.

**Un rappel dans Mémoire.** Si la Mémoire est activée sur votre compte et que vous n'avez pas enregistré votre voix, une carte "La mémoire fonctionne mieux quand elle connaît votre voix" s'affiche en bas de Mémoire. Plus d'infos explique pourquoi et propose Enregistrer ma voix. Fermez-la et elle revient dans quelques jours ; fermez-la plusieurs fois et elle ne revient plus.

**Vous désigner.** Le profil avec le badge "Vous" est celui du propriétaire. Si vous avez enregistré quelqu'un d'autre en premier, ou si vous avez plusieurs profils, touchez "C'est ma voix" sur le bon.

**Les autres personnes.** Vous pouvez aussi enregistrer la voix de vos collègues, depuis une réunion : ouvrez la transcription, touchez le nom d'un intervenant et choisissez "Enregistrer la voix". Leurs prochaines réunions seront libellées automatiquement. Les profils peuvent être renommés (crayon) ou supprimés (balayage). "Supprimer tous les profils" les efface tous ; vous pouvez toujours les recréer.

**Tester l'ID vocale**, sur le même écran, lance une vérification rapide. Si deux profils se ressemblent, une section "Avertissements de reconnaissance" vous le signale.

**L'améliorer.** Un nouvel enregistrement remplace votre voix enregistrée ; recommencer dans un endroit plus calme est la façon d'obtenir de meilleures correspondances.

**Où elle est stockée.** L'audio d'enregistrement et les empreintes vocales restent sur le téléphone. Si la Synchronisation iCloud est activée, elles suivent sur vos autres appareils via votre iCloud privé, pour que vous n'ayez pas à recommencer sur l'iPad.

Si vous vous passez complètement de l'ID vocale, l'app sépare quand même les intervenants ; elle les appelle simplement Intervenant 1, Intervenant 2, et ainsi de suite jusqu'à ce que vous les nommiez.
