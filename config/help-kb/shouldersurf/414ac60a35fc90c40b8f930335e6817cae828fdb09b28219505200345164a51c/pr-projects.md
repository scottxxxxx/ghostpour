A project is a folder with a brain. Meetings filed into it share context: Project Chat reads across them, Memory scopes its patches to it, and the prep card knows which one you're walking into.

**Sort the list.** Review > Projects has a Sort by row above the list. Date starts with the most recent meeting first, Name starts A to Z, and tapping the one you're on again flips the order. Your choice is kept.

**Create one.** Review > Projects > +. Name, icon, and an optional description. The description is sent with questions ("Helps the AI understand your project context"), so a sentence about what the project is pays off. You can also type a new project name in the project badge under the orb before you start a meeting (the project is made when recording starts), and the Copilot tab offers to create one when a calendar event has no project yet.

**Inside a project:** its meetings, Project Chat ("Ask about this project"), Notes, Action items, and the people who show up.

**Notes.** Reminders, decisions, contacts, or plain notes. They're included in Project Chat prompts, so a note like "Client prefers Tuesday calls" gets used. A note can have a due date and an "Add to iOS Reminders" switch.

**Action items.** What the server extracted from the project's meetings ("N open," "N to confirm"), plus anything you add with +: what needs doing, whose it is, a due date. Mark done or cleared, reopen, see overdue. Hand-written items are stored on the phone until the server accepts them ("On this phone only," with Retry). Tap the pencil on an open item to change its text, owner or date.

**The ⋯ menu:** Rename Project, Edit Description, Change Icon, Change Color (the colored bar on its card), Send to Shoulder Surf User, People Only in This Project, Delete Project.

**Moving a meeting.** On the meeting page tap the project pill and pick another project. In a project's meeting list there's also "Remove from Project." Memory follows the move.

**Renaming** cascades to the meetings and to Memory.

**Deleting a project** untags its meetings; it doesn't delete them. What the project taught Memory is kept and stays tied to it, so nothing leaks into your other projects.
